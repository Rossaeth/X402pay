The protocol

What happens on a call

Every request follows the same four-step exchange — this is the actual order of operations, not a marketing sequence.

01

Client requests the endpoint

Any HTTP client — a script, an agent, a browser — calls GET /api/price/bitcoin like a normal API.

02

Server replies 402

No payment yet, so the server returns 402 Payment Required with the exact price and settlement details attached.

03

Client settles in USDC

The client's wallet signs a payment on Base and retries the request with proof of payment attached.

04

Server returns 200 with data

Payment verifies against the CDP Facilitator, and the response comes back with the actual price data — same request, now paid.
